# Local website fonts

Barlow Condensed (500, 600, 700, 800) and DM Sans (400, 500, 600, 700) are served locally. Their font-face declarations are in `app/globals.css`; the original Google Fonts response and a local URL version are retained here as source records.

Both families use the SIL Open Font License. The corresponding license files are included in this directory. Font sources are recorded in `google-fonts.css`.
